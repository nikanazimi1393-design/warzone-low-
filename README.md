# 🎮 WARZONE 3D — Battle Royale (First Person)

بازی بتل‌رویال **اول‌شخص سه‌بعدی** تک‌فایل با Three.js — ۲۵ اپراتور، آخرین نفر زنده برنده‌ست.

## ▶️ اجرا

**آنلاین (GitHub Pages):**
`https://nikanazimi1393-design.github.io/warzone-low-/`

**لوکال:** کافیه `index.html` رو با دابل‌کلیک توی مرورگر باز کنی (برای لود Three.js اینترنت لازمه).

## 🎯 گیم‌پلی

- 🪂 فرود با لوداوت انتخابی (M4A1 / MP5 / HDR / Shotgun)
- 👥 ۲۴ بات هوشمند: لوت می‌کنن، به زون فرار می‌کنن، استریف می‌زنن، مدکیت می‌زنن
- ☁️ زون گازی که هی کوچیک میشه — داخل دایره سفید بمون!
- 🔫 ۶ سلاح با تریسر، مازل‌فلش، هدشات ×۲
- 📦 صندوق تدارکات، 🛡️ آرمور، 💊 مدکیت
- 🛰️ کیل‌استریک: UAV با ۳ کیل، حمله هوایی با ۵ کیل
- 🗺️ مینی‌مپ + نقشه تاکتیکی + کیل‌فید + قطب‌نما

## ⌨️ کنترل

| کلید | عمل |
|---|---|
| WASD / جهت‌نما | حرکت |
| موس | چرخش دوربین (اول‌شخص) |
| کلیک چپ | شلیک |
| کلیک راست | نشانه‌گیری / اسکوپ |
| R | تعویض خشاب |
| E | برداشتن لوت / باز کردن صندوق |
| 1 / 2 / Q | تعویض سلاح |
| Shift | دویدن |
| Space | پرش |
| H | مدکیت |
| M | نقشه تاکتیکی |
| U / K | پهپاد / حمله هوایی |
| `[` و `]` | کم/زیاد کردن حساسیت موس |

> اول روی صفحه کلیک کن تا موس قفل بشه (Pointer Lock).

## 🛠️ تکنولوژی

- تک‌فایل HTML (~۱۱۰۰ خط) — بدون بیلد، بدون نصب
- [Three.js](https://threejs.org/) از CDN برای گرافیک سه‌بعدی
- Web Audio API برای صداها (شلیک، کیل، زون...)
